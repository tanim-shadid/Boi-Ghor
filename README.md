#  BOI GHOR

An online bookstore platform where users can browse and manage books.
Built with **Node.js, Express, and MongoDB**.

---

#  Project Description

**Boi Ghor** is a full-stack bookstore application designed to manage books and users.

Users can browse available books, while administrators can add, update, and remove books from the system.

The goal of this project is to practice backend development, REST APIs, and database integration.

---

#  Features

* User authentication
* Add new books
* Update book information
* Delete books
* View all books
* MongoDB database integration
* REST API architecture

#  Installation Guide

### 1. Clone the repository

```
git clone https://github.com/yourusername/Boi-Ghor.git
```

### 2. Go to the project folder

```
cd Boi-Ghor
```

### 3. Install dependencies

```
npm install
```

### 4. Create a `.env` file

```
PORT=5000
MONGO_URI=your_mongodb_connection
```

### 5. Start the server

```
npm start
```

# 🔌 API Endpoints

| Method | Endpoint   | Description    |
| ------ | ---------- | -------------- |
| GET    | /books     | Get all books  |
| POST   | /books     | Add a new book |
| PUT    | /books/:id | Update a book  |
| DELETE | /books/:id | Delete a book  |
